# Open Scotland

Glasgow & Edinburgh council entities, money trails and ward intelligence.

**Live site:** https://mydugalbie-png.github.io/edinburgh-public-map/

## Features
- Glasgow entity list with hard 2024/25 related-party figures
- Click any ALEO name for a dedicated detail page (financials, ownership, money trails, sources)
- Ownership tree, money trails, priority ward intelligence
- Edinburgh summary retained

## Data sources
- Glasgow City Council Annual Accounts 2024/25 Note 16 (Related Party Transactions)
- Companies House filings
- Ward intelligence FOI work
